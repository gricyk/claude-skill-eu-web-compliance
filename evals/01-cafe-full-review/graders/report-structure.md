The output is a findings report where: findings are grouped by regulation (e.g. GDPR, ePrivacy, AI Act, DSA, accessibility); each finding states the provision, evidence pointing to a file or page element in the reviewed site, a risk label that is one of info / gap / likely violation, and a confidence level. Pass only if this structure is present for essentially all findings. A loose bullet list of tips with no per-finding provision, evidence, risk label and confidence is a fail.
